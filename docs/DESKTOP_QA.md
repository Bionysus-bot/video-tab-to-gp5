# Windows 桌面版本机验收 · 2026-10-24

适用：`codex/windows-desktop`，基于网页 v0.3.0 的桌面测试构建。网页识谱算法和用户项目未迁移。

| 检查 | 结果 |
| --- | --- |
| 后端回归 | 150 项测试通过 |
| GBK 环境日志 | UTF-8 输出正常，含中文与原故障字符 |
| EXE 独立识谱 | PATH 仅保留 Windows 系统目录；创建五弦 TAB PDF、识谱、下载并读回 GP5；四个第五弦 7 品音全部一致 |
| 桌面窗口 | WebView2 显示工作区，页面资源和像素字体加载成功 |
| 会话与退出 | 无会话请求返回 403；正常退出后后台结束、端口关闭 |
| 安装包 | 隔离目录安装成功；安装后再次通过真实 PDF → GP5 与窗口测试 |
| 测试卸载 | 卸载成功，程序目录之外的测试 GP5 和项目保留 |
| 便携包 | ZIP 全部文件 CRC 校验通过，包含运行时证书资源；不含用户 storage 项目 |
| 桌面快捷方式 | 安装配置明确使用当前用户桌面与开始菜单，并设置工作目录；默认勾选创建桌面入口；复用正式 Icons/Tasks 配置的隔离安装器验证默认、勾选、取消三种情况通过 |

已修复两项打包启动故障：无控制台环境的 GBK 编码错误，以及 Python 证书资源缺失导致的后台健康检查超时。桌面控制接口置于前端静态挂载之前，确保关机请求可达。

用户随后反馈安装时勾选桌面快捷方式但未出现。检查确认开始菜单入口和安装目标存在，桌面入口缺失；已从开始菜单入口补建。缺少该次安装日志，尚不能确认原始漏建原因。更新安装器后，在隔离目录验证了快捷方式选项行为，未重新安装或卸载用户的现有程序。

尚未在干净的另一台 Windows 机器验收，也未完成原生保存对话框的人工点击测试；GP5 下载接口及实际文件读回已经验证。WebView2 为外部运行环境，Ollama 仍为可选。当前安装包未签名，公开再分发的第三方材料准备见 [desktop/THIRD_PARTY.md](../desktop/THIRD_PARTY.md)。
