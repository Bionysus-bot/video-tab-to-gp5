# 五弦贝斯支持

日期：2026-10-24。分支：`codex/five-string-bass`，从已通过功能测试的 `880f1b3` 新建，可回退原分支 `codex/automated-workspace`。

## 使用

1. 新版工作区准备素材，在乐器中选择“五弦贝斯”；或在“设置 → 乐谱”中选择。
2. 标准调弦按低到高显示 B、E、A、D、G，新增全降半音、全降全音、Drop A 预设。
3. 选择纯 TAB 或五线谱＋TAB，选区须包含全部五根 TAB 弦线；联合谱还需包括上方五线谱。
4. 开始识谱，在第三步编辑第五弦音符、确认小节及下载 GP5，操作与四弦相同。

已有乐谱切换调弦或弦数后需另存修改，设置确认会取消。若已有第五弦音符，切回四弦会阻止并提示，避免隐藏或丢失音符。历史版本不会自动变成五弦，已有自定义调弦也不会自动替换。

## 兼容方式

- 新增独立的五弦调弦预设、弦数选择组件及专项测试。
- 请求接口从仅四弦扩展为四或五弦，默认仍是原四弦标准调弦。
- 复用已有读取器、音符模型、版本存储及 GP5 导出，没有重写核心音符和节奏算法。
- 编辑器将弦号选项按调弦长度生成，原默认仍为四弦。
- 仅五弦准备流程启用等间距“五线谱＋五弦 TAB”配对兼容；未显式启用的四弦、旧入口继续使用原规则。旧版界面不新增五弦控件。

## 验证

- 最终完整回归 148 项通过，包含原有 143 项与新增 5 项；前端类型检查和生产构建通过。
- 新增检查覆盖五弦请求、非法调弦、四弦默认值、纯 TAB 第五弦读取、联合谱第 5 弦节奏对应、等间距上下五条线区分、确认和实际五弦 GP5 回读。
- 独立合成五弦谱面从真实浏览器启动识谱，没有模拟 OCR：读出最低弦四个 7 品四分音符，生成一小节 GP5，五根弦与低音 B 调弦正确。
- 浏览器编辑首音为第五弦 10 品、确认并下载，回读保留修改且去掉标注；切回四弦的防丢音保护已验证。
- 原项目 JSON / GP5 测试前后校验一致。测试项目归档在本机 `.runtime/qa-projects/`，不提交用户素材。

本轮五弦联合谱使用合成图与数字 OCR 桩进行节奏及关联验证，真实五弦整曲、不同字体和实际 Guitar Pro 听奏仍需用用户样本验收。低音 B 是新增的默认五弦布局，高音 C 布局不提供专用预设。
