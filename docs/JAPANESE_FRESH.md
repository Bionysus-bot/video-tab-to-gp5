## 视觉约束

- 米白 `#fafaf8` 背景，内嵌 SVG 纸纹；白色主要表面，不使用深色背景。
- 天蓝 `#64b5f6`、薄荷 `#98d8c8`、浅粉 `#ffb7c5`、粉蓝 `#b8d4e3` 作为少量点缀。
- 主标题和关键标题 `#242c37`，正文 `#465264`，次要说明 `#697789`；标题关键词以 `#559ddd` 点缀，必要操作文字使用深色。
- 标题 600，步骤和操作文字 500，正文和输入 400；标题 30–44px、正文 15px，次要信息 12–14px。不使用大写装饰文字。
- 主要按钮采用浅蓝 `#a9d3f5` 与深色 `#233c52`，背景保持暖白；薄荷、浅粉仅作辅助状态点缀。
- 删除重复眉题、宣传引导、常驻免责声明；保留选区要求、参数单位、未保存状态、确认范围、错误原因和版权说明。
- 暖中性色 `#d4d4cf`，边界通常 0.5px、30–40% 透明度；输入底线可使用原色。
- 无可见阴影，无粗边框 / 单侧强调条；圆角 12–20px。
- 各主要工作视图有一幅植物 SVG 线描，装饰不接收焦点，设置 aria-hidden。
- 首屏以功能区可见为先：桌面页头 76px、步骤导航 56px，主区上边距 24–28px，标题底部间距 24px；窄屏同步压缩。横向布局保持原样，避免用宣传页式留白挤走操作区。
- 设置面板相对画布略向下错位，形成轻微不对称。队列、工具条为平面分区，避免卡片内再套卡片。

## 输入与交互

- 文本、数字和选择输入采用底线与浮动标签；原图坐标仍是实际像素，样式不能影响映射。
- 鼠标悬停只轻移约 0.5px，辅以透明浅色背景，不使用缩放或阴影。
- 颜色、边界、透明度、移动统一 500ms ease-in-out。
- 键盘焦点通过细线颜色和链接 / 按钮下划线表达，不使用粗 ring 或 glow。
- reduced-motion 关闭过渡及位移；禁用态仍保留可读的原因。
- 主要按钮采用浅蓝背景与深色文字。参考模板的浅蓝配白字对比不足，因此按同份规范的 WCAG AA 要求优先保证可读性。

## 实现方式与边界

项目沿用普通 CSS，无 Tailwind 运行时。令牌以 CSS 变量和对应语义类实现同等效果，不添加不生效的工具类充数。

主要文件：`frontend/src/studio.css`、`frontend/src/pages/Studio.tsx`、`frontend/src/components/Botanical.tsx`。旧界面通过 `?legacy=1` 保留原行为，新工作区的样式限定在 `.studio` 下，不用旧版外观作为新版本设计依据。
