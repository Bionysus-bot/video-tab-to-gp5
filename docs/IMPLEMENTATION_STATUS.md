## 已实现

批量确认：第三步可一次保存修改并确认所有未确认小节，已确认小节不重复处理；错误拍数、缺失音符、无对应前音的延音及编号冲突会跳过，保留原疑点并显示原因。所有修改统一另存一个版本，沿用并发冲突检查。44 项相关检查通过；独立浏览器项目验证了未保存品位修改、确认 2 个小节并跳过 1 个错误小节，实际下载 GP5 回读确认文字按状态清除，原谱与既有 GP5 校验值保持一致。

补充：第三步加入“保存并确认此小节”。人工接受当前音符和时值后，保存独立版本并更新 GP5；已确认小节不再带 CHECK 等核对标记，未确认小节保留。不能借确认跳过错误拍数、无候选音高或结构冲突；编辑已确认小节会取消确认。41 项相关检查通过，并在浏览器测试副本上确认后下载实际 GP5，验证第一个小节无文字、改后的品位保留、第二个小节仍有标注。用户原有乐谱未用于此项写操作。

## 保守策略与尚未完成的验收

- 人工修改目前按整小节保护，比逐字段保护更保守；同小节其他音符不会被自动改写。旧数据没有修改来源，导入时同样保守保护。
- 跨行的可见弧线规则已实现，同一行跨小节可使用图像证据；跨图片完全缺失的弧线仍依赖括号、上下文或人工确认，不能保证修复所有延音。
- PDF 区域以第一页的相对位置应用于后续页；混合版式需要分项目导入，尚无逐页独立区域编辑。
- 过滤画面和片段保存在版本记录；新界面尚未完整迁移逐项恢复被过滤画面、手动拼接、原 PDF 导出等全部高级工具。相关旧工具仍从旧版界面使用，且旧项目文件与新版本数据互相隔离，不支持双向同步。
- 本机 Ollama 检查时未运行。已保留失败 / 超时退路与局部修改校验，真实模型推理效果没有在本轮验收中重新确认。
- 程序回读不等于 Guitar Pro 实际听奏；新草稿的实际播放、整曲人工修正量和独立曲目泛化评测仍待核对。
- 安装验证目前限现有 Windows 环境，未在全新机器复现；T15 / T16 的完整发布验收尚未完成，因此不作为正式稳定发布。

## 使用与回退

默认页面为新工作区；`/?legacy=1` 打开旧界面。旧版编辑只影响旧目录，不能修改新版本包；新旧视图请勿当作同步编辑器。

新数据在项目 `score/v2/` 下，旧 `score.json`、原素材及既有 GP5 保留。新任务对已有人工结果另存版本；需主动选择结果版本后再编辑。程序外部 Guitar Pro 的手动修改不会自动同步。

代码回退到原标签即可回到原界面；保留 `score/v2/` 数据，不删除用户素材。升级不会把用户外部修正文件替换成机器候选。
