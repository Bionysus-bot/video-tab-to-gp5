# 视频 / PDF 转 GP5 UI 与交互设计

版本：1.0 · 2026-10-23  
依据：[PRD](PRD.md)、用户新增视觉要求 · 配合：[技术设计](TECHNICAL_DESIGN.md)  
状态：信息架构已实施，视觉规范已按用户指定的日系清新风更新。下方原始线框用于说明分区；视觉参数以风格规范为准。

> 2026-10-23 风格更新：用户指定 `japanese-fresh`（日系清新风）。视觉规范以 [日系清新风实施规范](JAPANESE_FRESH.md) 为准，覆盖本文原有配色、字重、边框、阴影、焦点和动效数值。多工作视图、来源对照及版本保护交互仍保留。新工作区已进入实现与验收阶段，旧版入口只用于兼容回退。

## 1. 设计方向

简洁、留白充分的日系清新音乐工作台。以米白纸感为底，天蓝、薄荷及粉蓝作少量点缀，让黑白谱面成为视觉中心。采用轻字重、植物线描、发丝边界和底线输入，不以大量卡片、粗边框和全屏彩色告警制造重点。

当前问题是信息架构：处理、参数、说明、校对及下载集中在右侧 360px 窄栏，左侧预览与后续工作脱节。新方案将工作分成准备、处理和结果三种视图；设置进入抽屉，校对进入专用工作区，不把全部内容换成更多折叠面板。

浅色作为新默认主题是本设计提议；旧深色体验可在后续主题选项保留。近期先做好一个完整、可读的主题，避免两套主题都不完整。

## 2. 全局信息架构

顶部是轻量项目栏：产品名、项目 / 素材名、保存状态，右侧为版本、设置与帮助。第二层为三个视图入口：**准备素材 / 自动识谱 / 结果校对**。任务可后台继续，切换视图不取消任务、不重新导入。

| 内容 | 新位置 |
| --- | --- |
| 导入视频 / PDF、切换项目 | 准备视图的素材入口 / 项目菜单 |
| 区域框选与坐标 | 主预览画布及紧邻画布的工具条 |
| 谱面类型、四弦贝斯配置 | 准备视图的短配置区 |
| 进度、补读、局部复核 | 自动识谱视图的阶段时间线 |
| 草稿下载与内容摘要 | 处理视图就绪区域、结果视图顶部 |
| 疑点列表、原图、编辑器 | 结果校对视图的并排区域 |
| 模型、抽帧、PDF、高级修复 | 分组设置抽屉，按任务上下文显示 |
| 日志、识别解释 | 对应阶段或疑点的“详情”，按需打开 |
| 旧版本 / 回退 | 顶部版本菜单，显示版本时间和来源 |

全局同一时刻只有一个实心主按钮。已有草稿且仍复核时，下载为主按钮，取消 / 查看进度使用次级样式。

## 3. 桌面布局线框

### 3.1 准备素材

```text
┌ 产品名   项目名称 · 已保存                  版本   设置   帮助 ┐
│ 准备素材 ━━━      自动识谱          结果校对                  │
├───────────────────────────────────────┬─────────────────────┤
│ 素材名 · 视频 / PDF                   │ 转谱配置            │
│                                       │ 谱面类型            │
│          大幅原图 / 区域框选           │ ○ 纯 TAB            │
│                                       │ ○ 五线谱＋TAB       │
│                                       │ 四弦贝斯 · 默认调弦 │
│ 时间轴 / 页码                         │ [更多乐谱设置]      │
│ X [ ]  Y [ ]  宽 [ ]  高 [ ]         │ 区域确认提示        │
├───────────────────────────────────────┴─────────────────────┤
│ 原始素材保留                        [开始自动识谱 →]        │
└─────────────────────────────────────────────────────────────┘
```

桌面准备区约为可用宽度的 72% / 28%，配置区 280–320px，只放启动必要条件。没有文件时中央显示视频 / PDF 两个明确入口和最近项目，不显示大量无效控件。联合谱提示只需一句“请框入上方五线谱与下方 TAB”。

视频的时间选择和 ROI 使用同一主画布，避免两份同帧预览占满页面。PDF 使用页码、缩放与区域控制；页面区域可复制到其他页，但需预览确认，不假定所有页布局一致。

### 3.2 自动识谱

```text
┌ 准备素材        自动识谱 ━━━        结果校对                 ┐
│ 正在复核节奏                         已运行 02:10    [取消] │
├──────────────────────────────────────┬──────────────────────┤
│ 当前谱行 / 小节预览                  │ ✓ 整理谱面           │
│                                      │ ✓ 本地识别           │
│ 正在处理的位置轻量高亮               │ ● 补读与复核         │
│                                      │ ○ 更新草稿           │
├──────────────────────────────────────┴──────────────────────┤
│ 当前草稿 · 150 小节 · 8 个疑点 · 2 个缺失                   │
│ 复核仍在进行                查看疑点    [下载当前 GP5 草稿] │
└─────────────────────────────────────────────────────────────┘
```

只显示真实可计算进度。总工作量未知时显示当前阶段及计数，不伪造平滑百分比或准确剩余时间。日志放阶段详情；正常日志不自动撑高页面。取消后保留已有草稿，并提示继续处理入口。

### 3.3 结果校对

```text
┌ 草稿已生成 · 170 小节 · 9 个待确认       [下载 GP5 草稿]      ┐
├───────────────┬─────────────────────────────────────────────┤
│ 疑点 9        │ 第 113 小节 · 第 3 拍位                     │
│ 类型筛选      │ 来源图：视频 03:24 / PDF 第 2 页             │
│               │                                             │
│ 12 时值疑点   │      完整小节 + 局部放大 / 关联叠加          │
│ 16 延音疑点   │                                             │
│ 113 品位疑点 ●├─────────────────────────────────────────────┤
│ …             │ 品位 [10] 弦 [4] 时值 [八分] 延音 [ ]      │
│               │ 候选与原因 · 自动修订记录                    │
│               │ 上一疑点   下一疑点          [保存修改]     │
└───────────────┴─────────────────────────────────────────────┘
```

左侧 240–280px 是可滚动疑点队列，右侧为大幅对照画布，下方短编辑区。宽屏可将编辑区置于画布右侧，但须保证主画布足够宽；不强制固定三栏。无疑点时显示谱行总览和“程序未发现待处理问题”，不能写成“全部音符准确”。

长谱默认适合宽度；需要时放大、水平拖动画布。数字不能为了适应卡片宽度缩到不可读。一次挂载选中的小节编辑器；切换“全部小节”后仍按选择浏览，不全量展开。

## 4. 视觉规范

### 4.1 色彩令牌（初稿）

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#F4F3EF` | 暖灰白底 |
| 主表面 | `#FFFFFF` | 画布、编辑区、抽屉 |
| 次表面 | `#EBEEE9` | 选中背景、分组条 |
| 正文 | `#27342F` | 标题与正文 |
| 次文字 | `#59665E` | 来源、说明、时间 |
| 边界 | `#D8DED7` | 装饰分隔；不能单独承担控件识别 |
| 控件边界 | `#7C8B81` | 输入框边界及必要轮廓 |
| 主强调 | `#426856` | 主按钮、当前视图、焦点 |
| 强调浅底 | `#E2ECE5` | 选择、已保存状态 |
| 提醒文字 / 浅底 | `#765728` / `#F3EBDD` | 待确认、缺失提示 |
| 错误文字 / 浅底 | `#984A43` / `#F5E6E3` | 输入失败、导出失败 |

低饱和不等于低对比。主按钮白字与普通文字对比至少 4.5:1；关键控件及焦点与相邻背景至少 3:1，开发时逐状态测量。必要时调整以上色值，优先可读性。

### 4.2 排版与间距

- 使用系统中文无衬线字体，不依赖在线字体；数字计数采用等宽数字特性。
- 主标题 24px / 32px，区标题 18px / 26px，正文 15px / 24px，标签与来源 13px / 20px。
- 间距以 4px 为单位，主要采用 8 / 12 / 16 / 24 / 32px；工作区边距 24–32px。
- 按钮高度 40px，常规输入 40px，紧凑工具条可为 36px；不通过缩小所有字体压缩信息。
- 分区使用留白与细分隔；圆角 8–12px，阴影只用于浮层，不给每个控件加卡片。
- 图标使用统一线条 SVG，与文字搭配；不使用 emoji 作为关键动作图标。
- 不使用大面积渐变、霓虹色、玻璃效果或无业务用途的图表装饰。

## 5. 核心交互

### 区域框选

拖动时仅即时绘制，松开后保存；数值编辑按确认 / 失焦提交。显示“正在保存 / 已保存 / 保存失败”，失败可重试。主按钮在区域尚未保存时等待提交，并说明原因。支持键盘微调及重置区域，不能只靠鼠标精确操作。

### 设置抽屉

设置按“乐谱、识谱模型、视频 / PDF、高级”分组，桌面宽约 420px，小屏全屏。默认呈现当前流程相关项。修改识别相关设置时提示“用于下次识谱”，不隐式改变已生成结果。帮助作为分组说明和独立文档链接，不在主页面连续堆放长段落。

### 疑点处理

队列显示类型、小节 / 拍位和一句原因；普通 OCR 提醒为次级过滤项。选中疑点后高亮具体位置，并用图例解释颜色。跨行或跨小节延音可同时查看相邻来源。证据不足的项目显示“仍不确定”，不是强制选择“确认正确”。

保存产生新版本，顶部显示未保存 / 正在保存 / 已保存；保存失败保留输入。自动建议显示修改前后值及应用按钮。人工保护字段以文字或锁图标标明，用户可主动修改，程序不静默覆盖。

### 下载与结果

默认动作始终叫“下载 GP5 草稿”。旁边显示结果版本和疑点 / 缺失数；问题报告为次级下载。严格导出藏在“更多导出”中，条件不满足时给出说明。文件未就绪显示生成进度；失败显示原因与重试，避免没有解释的禁用按钮。

### 未保存与版本切换

切换小节、项目或版本遇到未保存编辑时，提供保存、放弃、留在当前页三种明确动作。版本列表展示产生方式、时间、疑点数与是否含人工修改，切换不删除历史。

## 6. 响应式与可访问性

| 可用宽度 | 布局 |
| --- | --- |
| ≥1280px | 准备区主画布＋短配置；结果为队列＋画布 / 编辑区 |
| 960–1279px | 缩窄队列，编辑区固定在画布下方；仍保留并排对照 |
| <960px | 队列为可切换面板，设置全屏；画布与编辑纵排，仅保留当前任务内容 |

应用宽度可到 1600px，居中但不挤成窄条；在 1920px 屏幕合理利用宽度。1366×768、1440×900、1920×1080 及 200% 缩放列入检查。谱面可在画布内平移，页面自身不应意外横向滚动。

所有控件可键盘访问，焦点可见；抽屉 / 对话框管理焦点并在关闭后归还。状态不单靠颜色表达；错误与输入关联，动态状态使用适度 live region，避免每秒重复朗读进度。动效 120–180ms，尊重减少动态效果设置。

## 7. 前端实现边界

拆分页面与组件，复用现有 API 和 ROI、谱面编辑能力；先做布局与组件职责，再迁移行为。样式采用 CSS 变量和组件作用域，清理泛化 button / details 规则，避免新旧界面互相污染。

新界面可先以只读真实数据及固定测试状态搭建，通过布局检查后接入新任务 API。不得为展示效果自动重识谱或覆写用户结果。旧功能入口迁移表需逐项核对，避免隐藏高级操作时误删功能。

## 8. UI 验收清单

- 桌面主页面不再把全部业务压进右侧单列；准备、进度和校对拥有各自主要区域。
- 正常流程不打开设置、帮助或日志也能完成；配置项只在必要时出现。
- 一次开始后可查看处理状态、下载已有草稿，无需滚过大量说明寻找按钮。
- 疑点选择后可同时看到原因、来源谱面和编辑字段，无需在上下长页面来回找位置。
- 检查空项目、视频、PDF、处理中、草稿可下载仍复核、取消、失败、零疑点、有缺失、未保存编辑及旧项目等状态。
- 关键布局在目标分辨率、键盘、200% 缩放和对比度检查下可用；保留截图供版本比较。

本设计在实现中可以调整尺寸与组件细节，但不能退回“所有功能放一列、靠折叠隐藏”的信息架构。
